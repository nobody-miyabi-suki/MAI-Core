# MAI Core

ESP32 based personal media and control core system.

MAI Core is a custom embedded project built around ESP32, TFT display and a web-based control system.

## Features

- ESP32 firmware
- ST7735 TFT interface
- SPIFFS based media system
- Image and GIF playback
- WiFi AP + Station mode
- Web dashboard
- System information API
- File upload and delete system
- Remote LED control
- Boot animation system

## Hardware

- ESP32 Dev Module
- ST7735 128x160 TFT Display
- SPIFFS Storage
- WiFi
